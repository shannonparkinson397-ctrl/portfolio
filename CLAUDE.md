# Portfolio

## Описание
Веб-портфолио с многоязычной поддержкой (русский/английский). Статический сайт с информацией об услугах DevOps и QA автоматизации.

## Архитектура

### Структура
```
portfolio/
├── index.html              # Главная страница (35KB)
├── en.html                 # Английская версия
├── offer.html              # Страница оффера
├── devops-automation.html  # DevOps услуги
├── privacy.html / privacy-en.html
├── cookies.html / cookies-en.html
├── consent.html / consent-en.html
├── 404.html
└── preview.html
```

## Контент

### Основные страницы
- **index.html** - главная страница портфолио
- **en.html** - английская версия
- **offer.html** - описание услуг и оффер
- **devops-automation.html** - DevOps автоматизация

### Юридические страницы
- Privacy Policy (русский/английский)
- Cookie Policy (русский/английский)
- Consent форма (русский/английский)

### Контент-гайды
- **content-devops-automation-guide.md** - гайд по DevOps контенту
- **content-qa-automation-guide.md** - гайд по QA контенту

## Ресурсы
- **og-image.svg** - Open Graph изображение для соцсетей
- **FAVICON_TODO.txt** - заметка о favicon

## Git
Проект под версионным контролем (`.git/`)

## Применение
Статическое портфолио для презентации услуг DevOps и QA автоматизации. Поддержка двух языков для международной аудитории.
